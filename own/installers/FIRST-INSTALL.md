# codex-own 完整安装包

首次安装可选择图形安装包，后续通过应用内“更新”菜单从 npm 获取增量资源。公开的 `@petercjl/codex-own` 命令行安装方式继续保留。

## 下载安装包

从维护者提供的共享目录，或本项目 GitHub Release 中标题为“codex-own <版本> 完整安装包”的页面下载当前 Windows 版本：

| 系统 | 文件 |
| --- | --- |
| Windows x64 | `codex-own-<版本>-windows-x64-setup.exe` |

安装包包含桌面应用和完整运行环境，下载完成后可离线安装。首次打开后按提示完成企业钉钉登录，在线使用已授权的模型。请预留至少 10 GB 空间，安装前保存任务并退出已有的 codex-own。

## Windows

1. 双击 Setup EXE，进入安装界面。
2. 企业员工在“API 配置文件”页面保持文件选项为空，继续安装。使用企业登录获取模型授权。
3. 点击安装，等待完整资源校验与安装完成。
4. 从 Windows 开始菜单找到 **codex-own** 并打开，按提示完成企业钉钉授权和登录。
5. 按应用提示完成重新打开，即可使用已授权的模型。生图能力按员工授权启用。

应用安装在当前用户的 `%LOCALAPPDATA%\Programs\codex-own\current`，独立数据目录为 `%LOCALAPPDATA%\codex-own-independent`。安装器提供 Windows 应用卸载入口；卸载程序时保留配置、密钥、对话和恢复备份。

## 后续更新与数据

应用会自动检查并在后台准备更新，准备完成后提示可重启安装。完成当前任务后，打开 **更新 → 检查 codex-own 更新**，点击“重启并安装”并确认。下载和准备阶段保持当前任务运行。

从 0.6.14 起，更新服务自动选择可用下载源，官方源连接失败时尝试内置国内源，员工无需配置代理。资源按发布清单校验，下载失败可重试并复用已校验内容；网络暂不可用时保留当前安装。

API 文件只在本机读取，密钥不进入安装包和更新服务器。正式版、开发版及原版 Codex 使用各自的数据目录。重复安装保留已有配置与对话；较旧安装包会拒绝覆盖更新版本。未知已有安装会保留原目录，并提示先进行修复。

安装成功后可删除下载的 EXE；应用内更新无需保留首次安装文件。

## 当前验证与签名状态

发布附带安装包 SHA-256 和 Windows 验证记录。自动化验证覆盖 Windows Setup 执行、离线安装、重复安装、API 配置导入、独立运行时及现有更新器接管。交互式界面操作与真实下载后的系统提示需在使用机器上继续验收。

Windows 安装器尚未配置组织持有的受信任 Authenticode 证书。系统可能提示无法验证发布者。请核对本项目下载来源与附带校验清单，再按系统针对该应用提供的确认流程操作；不要全局关闭系统保护。公司广泛分发前应完成可信签名、公证与真实机器验收。

## Mac 历史备份

Mac 使用项目本地开发构建；以下是旧版 Mac 分发记录。后续正式版本只提供 Windows 安装器。


1. 双击 DMG，打开其中的 **codex-own 安装器**。
2. 如需配置 API，点击“选择 API 配置 txt”，选取自己保存的文件。**请按文件实际位置选择**；已有配置时可跳过。
3. 点击“安装 codex-own”，等待完成。
4. 从 Finder 的“应用程序”中打开 **codex-own**。安装成功后可推出安装磁盘。

应用安装在 `/Applications/codex-own.app`，独立数据目录为 `~/Library/Application Support/codex-own-independent`。当前 Mac 目标为 Apple 芯片，安装账户需要具有“应用程序”目录的写入权限。
